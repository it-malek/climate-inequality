# Historical evidence and public derivatives

Some historical documents and execution records are labeled public derivatives prepared on 2026-10-23. Their explanations retain the recorded scientific decisions, dates, restrictions and limitations, while replacing incidental process wording or workstation locations with neutral descriptions. The edited wording is not claimed to have existed verbatim at the original date. Original records remain in the private recovery archive.

`reports/public_evidence_derivatives.json` identifies metadata records by their original and public byte hashes, exact edited JSON Pointers and reasons. Its protected semantic projection masks only those listed string leaves. Software versions, timestamps, argument order, input identities, result hashes and all unlisted values remain unchanged. `${RUN_ROOT}` and `${VIRTUAL_ENV}` are explicit portable placeholders, not claims about original execution locations.

`reports/public_document_derivatives.json` records original and public identities, precise byte spans, reasons and a protected byte projection for historical prose, descriptive JSON and comments or explanatory strings in source files. Each copy contains a disclosure. Scientific calculations, numerical constants, control flow, data and results are unchanged. Four historical contracts retain their methodological decisions and timing in these labeled copies. A few historical links point to the retained development branch, where their source documents remain available.

`python -m src.research_audit` checks the public hashes and protected projections. Original expected scientific citations and result manifests are retained. The two descriptive `m4_inventory_status.json` copies change only a scope-decision description and add a disclosure. The archival audit verifies them separately against their declared original identity and public projection and reports their count explicitly. Every other deterministic result-manifest artifact and the dashboard bundle still require original exact bytes. The audit does not describe a derivative as an original-byte match or authorize scientific execution.

The recorded hashes of original records and omitted text do not let a reader independently recover or authenticate withheld bytes. Comparing both protected projections requires the private originals. A public manifest is a transparent, reviewed identity record, not an independent guarantee against jointly altered files and manifests.

Historical snapshots retain their original strict scientific entrypoints. Those programs do not become derivative-aware retroactively. Use the verifier from this released tree to inspect a historical snapshot's public copies. Exact original-run verification or replay requires the preserved original records and historical execution environment. Public derivatives must never stand in for original bytes at a scientific execution gate.

Source citations, licenses and recorded contribution credits remain. Credit identifies the contribution recorded in the source history; it does not establish sole human authorship, current responsibility or a legal obligation to retain every historical automation notice. These editorial derivatives preserve the distinction between historical and corrected results and do not change the accepted scientific bundle.
